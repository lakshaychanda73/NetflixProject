# MahaRERA + Mumbai Real Estate — Self-Learning Program

A complete, self-paced executive-education program built around the official
**MahaRERA Agent Training Program (MATP)** syllabus (NAREDCO + REMI), extended with
practical brokerage skill, Mumbai market knowledge, due diligence and real estate finance.

**Goal:** pass the MahaRERA Certificate of Competency exam *and* be able to hold an
intelligent conversation with a developer, broker, investor or buyer in Mumbai.

## Two honesty notes — please read once

**1. Link verification.** Every link in this course came out of live web-search results,
so the pages are real and indexed. However, the sandbox this course was built in blocks
outbound page fetches, so I could **not** open each page to confirm its live HTTP status,
and I could **not** read YouTube video durations. Video run-times are therefore
**omitted rather than invented**. If a link 404s, the parent index page is given alongside
it in the Master Resource Library so you can re-find the document.

**2. RERA ≠ MahaRERA.** *RERA* is the central Act of Parliament (Act 16 of 2016).
*MahaRERA* is the regulator constituted for Maharashtra under it. The Act is the same
across India; the **rules, fees, forms, orders and circulars are Maharashtra-specific**.
Your exam is on the Maharashtra layer. This course keeps them separate everywhere.

**3. A numbering quirk in the official syllabus.** On the MATP page, Module 8's sub-topics
are numbered 9.1–9.7 and Module 9's are numbered 10.1–10.4, which collides with Module 10.
This course renumbers them correctly (8.1–8.7, 9.1–9.4). Don't be confused when you
cross-check against the website.
